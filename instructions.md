We want to build an interactive application using a React.js front end and a FastAPI back end. The application should visually explain how the Claude Code Harness works under the hood, the whole loop cycle (including all relevant stages and concepts) in an interactive visualization.The user should really understand how Claude Code, the harness, the loop itself works after interacting with our application.  The user should be able to click on various icons and then see an explanation in a pop-up. The user should also have the option to ask questions about the visualization. This should be answered by a large language model. For that, we use Ollama with the Alibaba QWEN3.5 model ("qwen3.5:latest"), which is currently locally hosted on my computer.

We want to run the whole application in a Docker container; however, the Ollama model should be on my personal computer, so we don't want to download it for the Docker container as well. We want to use Docker Compose, and the whole application should start using a doc command.
For the Ollama model, we want to use the PydanticAI framework, and we also want to use the built-in logger to track the interactions and logging interactions with the model. When the user wants to chat with the model, it should be like on a website where they have this little pop-up message on the side. This allows a user to click on a bubble or something like that, so that then the window appears for the chat. The user should also be able to close this chat again.

We do not need any login, and we don't store sessions right now, so if the app is closed or terminated and we restart it, then nothing is saved. For the design, I like to have a style guide from the German Deutsche Bahn. So the German Railroad Company. If we open the application, we should see, or at least remember, that this is created by the Deutsche Bahn with these red, gray, and white color tones. If anything is ambiguous in my prompt or you miss information, then ask.
